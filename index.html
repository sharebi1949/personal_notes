连接 GitHub 仓库
笔记数据会保存到你 GitHub 仓库里的一个 JSON 文件。
手机和电脑填同样的配置，就能看到同一份笔记。
怎么获取 Token？
GitHub 头像 → Settings → Developer settings → Personal access tokens → 选 Fine-grained 或 Tokens (classic)

细粒度：Repository access 勾选你的仓库，Permissions → Contents → Read and write
经典：Select scopes 只勾 repo
导出：把全部笔记下载为一个 JSON 文件（本地备份）。
导入：选一个 JSON 文件覆盖当前全部数据，会同时写入 GitHub。
